ATTENTION

DO NOT MODIFY THESE TOOLS
Running a modified version of these tools can result in you being rate limited or, in extereme cases, account moderation. These tools are meant to facilitate the shopping experience and should not be used maliciously.

Multi-Reseller

The Multi-Reseller tool allows for the following:

  • List multiple items for resale at once
  • Allows for individual ID inputs as well as ranges
  • All listed items will have the same inputted price
Multi-Reseller

De-Lister

The De-Lister tool does the following:

  • Removes all items listed for resale by your account on the currently viewed page of sellers
  • There are no secondary inputs, only a confirmation message
De-Lister

Crate Opener

The Crate Opener tool allows for the following:

  • Open multiple Crates at once with no animations
  • Allows for individual ID inputs as well as ranges
  • You'll have to manually check Crate History to see what you received
Crate Opener
